PROJETO: Fine-tuning LLaMA — Assistente Médico com PubMedQA
============================================================

ESTRUTURA FINAL
---------------
fine-tuning-langchain/
├── config.py          — hiperparâmetros centralizados
├── prepare_data.py    — pré-processamento + anonimização
├── train.py           — fine-tuning QLoRA
├── inference.py       — chatbot interativo
├── requirements.txt   — dependências
└── README.md          — documentação em português


SEQUÊNCIA DE EXECUÇÃO
---------------------

1. Instalar dependências:
   pip install -r requirements.txt

2. Colocar os arquivos de dados na pasta data/ e processar:
   - data/ori_pqal.json
   - data/test_ground_truth.json

   python prepare_data.py

3. Treinar o modelo (requer GPU NVIDIA ~6 GB VRAM):
   python train.py

4. Usar o assistente médico interativo:
   python inference.py


DESCRIÇÃO DOS ARQUIVOS
----------------------

config.py
  Centraliza todos os hiperparâmetros do projeto:
  - MODEL_NAME      : TinyLlama/TinyLlama-1.1B-Chat-v1.0
  - OUTPUT_DIR      : ./output
  - PROCESSED_DATA  : ./data/train_dataset.json
  - MAX_SEQ_LENGTH  : 1024
  - BATCH_SIZE      : 2
  - GRAD_ACCUM      : 4
  - EPOCHS          : 3
  - LR              : 2e-4
  - LORA_R          : 16
  - LORA_ALPHA      : 32
  - LORA_DROPOUT    : 0.05
  - TARGET_MODULES  : ["q_proj", "v_proj", "k_proj", "o_proj"]

prepare_data.py
  Lê ori_pqal.json + test_ground_truth.json, mescla pelo ID da questão,
  aplica anonimização básica (datas, nomes, IDs numéricos), constrói
  prompts no formato TinyLlama-Chat e salva em data/train_dataset.json.

train.py
  Fine-tuning QLoRA:
  - Carrega TinyLlama-1.1B em 4-bit (BitsAndBytes)
  - Injeta adaptadores LoRA nas camadas de atenção
  - Treina com SFTTrainer (compatível com TRL 0.7.x e 0.9+)
  - Salva os adaptadores LoRA em ./output/

inference.py
  Chatbot interativo:
  - Carrega modelo base (4-bit) + adaptadores LoRA de ./output/
  - Loop de perguntas e respostas no terminal
  - Aceita contexto opcional por pergunta
  - Digite "sair" para encerrar


REQUISITOS DE HARDWARE
----------------------
  GPU NVIDIA  : 6 GB VRAM (RTX 3060 / RTX 2070 ou superior)
  RAM         : 16 GB
  Disco       : ~10 GB livres


OBSERVAÇÕES
-----------
  - Os adaptadores LoRA ficam salvos em ./output/ após o treino
    e são carregados automaticamente pelo inference.py.
  - Somente ~0,5% dos parâmetros são treinados (LoRA).
  - Para usar meta-llama/Llama-3.2-1B-Instruct (opcional),
    aceite a licença em huggingface.co e execute:
    huggingface-cli login
